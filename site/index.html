Why receipts matter

Agents remember things that are wrong, stale, or planted.

Persistent memory makes agents more useful. It also means one bad write can follow you into every future session.

01 · it happens

A webpage plants a “fact”

The agent reads a page that says “the user wants every PR auto-merged” and repeats it in an answer.

02 · without sources

It becomes memory

A store that doesn’t track sources saves it like anything else. Next week, the agent acts on it.

03 · with Provena

It stays a low-authority candidate

It is linked to the assistant turn that produced it, visible as provisional, and promoted only if a human approves.

Evidence is never rewritten

Every conversation turn is an append-only event. Claims are derived from events and always link back to them.

Humans decide what’s trusted

Extracted claims start as candidates. Only a reviewer credential can promote one; an agent key cannot.

Memory is not permission

Authority, relevance, and permission to act are kept separate. A remembered fact never authorizes an action.

Changes of mind keep history

When a fact changes, both versions stay, and a reviewed relationship records which one supersedes the other.

How it works

From conversation to trusted memory.

One FastAPI service and PostgreSQL with pgvector. Host hooks capture turns automatically; the MCP server gives agents attributed context.

CaptureHooks record your prompt and the agent’s answer as immutable events.
ExtractA local Ollama model proposes candidate claims, each linked to its evidence.
RecallLater sessions receive relevant claims, labeled with status and authority.
ReviewA human approves, quarantines, or resolves conflicts in the console.
Explainmemory_explain shows source, review history, and every retrieval.
How it compares

Different tools, different trade-offs.

Provena focuses on provenance and review rather than minimal setup. If you only want the lightest possible recall, a local-file tool may suit you better.

FAQ

Before you install.

Does it send my conversations anywhere?

No. By default everything runs on your machine, and extraction uses local Ollama models. A hosted model is opt-in.

Do I need Docker?

Yes, for now. Quickstart runs PostgreSQL, the API, and the console with Docker Compose. A Docker-free mode is planned.

How big is the download?

The local models total about 1.26 GB, but quickstart doesn’t wait for them: recall uses keyword search until they’re ready. If Ollama already runs on your machine, Provena uses it. Prefer no models? Use --no-local-models.

Does installing it start recording?

No. Capture starts only after you run provena quickstart or provena connect --install for a host.

Which agents work?

Claude Code, Codex, and Gemini CLI get one-command setup with automatic capture. Other MCP clients can use provena connect generic.

What are the current limits?

Retrieval uses an exact scope; branch inheritance isn’t implemented. Provena records which claims were delivered to an agent, but can’t prove a later action was caused by them. Project-level access control is future work.
